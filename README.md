# 🚀 Vibe Coding 연습용 글래스모피즘 계산기 (Vibe Glass Calculator)

바이브 코딩(Vibe Coding)을 직접 익히고 실습해 볼 수 있도록 AI 에이전트와 대화로 제작된 **스마트 글래스모피즘 계산기** 프로젝트입니다.

---

## 📁 프로젝트 파일 구조

* `index.html`: 앱의 기본 구조 및 HTML5 마크업
* `style.css`: 네온 다크 모드, 글래스모피즘(Glassmorphism), 애니메이션 스타일
* `script.js`: 사칙연산, 공학용 기능(제곱근, 제곱 등), 키보드 단축키, 히스토리 저장 로직
* `README.md`: 프로젝트 및 바이브 코딩 실습 가이드 문서

---

## 💻 앱 실행 방법

1. 생성된 폴더 내 `index.html` 파일을 크롬(Chrome)이나 원하는 웹 브라우저로 열어 실행합니다.
2. 마우스 클릭 또는 키보드 숫자키/연산자 키를 사용해 자유롭게 계산할 수 있습니다.

---

## 🎨 바이브 코딩 실습하기 (AI에게 변경 지시해보기)

지금 만든 계산기에 추가하고 싶은 기능이나 스타일을 **자연어(한국어)로 AI에게 지시하는 것**이 바로 바이브 코딩입니다!

아래 예시 프롬프트 중 하나를 복사해서 지금 대화창에 입력해보세요:

### 1. 디자인/테마 변경 지시 예시
> *"계산기 테마를 어두운 네온 스타일 대신 밝은 모드(Light Theme)와 파스텔 톤 색상으로 바꿔줘."*

### 2. 새로운 기능 추가 지시 예시
> *"계산기에 단위 변환기(예: 섭씨↔화씨, cm↔inch) 탭을 상단에 추가해줘."*

### 3. 기능 개선 지시 예시
> *"계산기 버튼을 누를 때마다 귀여운 효과음(Sound Effect)이 나도록 수정해줘."*
